--------------------------------------------------
 CÁCH XEM (KHÔNG CẦN INTERNET)
--------------------------------------------------
• Mở file  index.html  ở thư mục này bằng trình duyệt
  (kéo thả vào Chrome/Edge, hoặc double-click).
  → Đây là trang gallery, bấm vào từng card để mở 3 demo.

• Hoặc mở trực tiếp:
    cinematic-gemini/index.html
    cinematic-windland/index.html
    cinematic-sougen/index.html

• Khuyến nghị: Google Chrome hoặc Microsoft Edge (mới nhất).
• Toàn bộ thư viện (GSAP, Three.js), fonts và hình ảnh đã được
  đóng gói sẵn trong thư mục  _assets/  → chạy hoàn toàn offline.

--------------------------------------------------
 NẾU TRANG BỊ TRẮNG / LỖI KHI DOUBLE-CLICK
--------------------------------------------------
Một số cấu hình bảo mật của trình duyệt có thể chặn mở file cục bộ.
Khi đó hãy chạy qua một web server tĩnh (vẫn KHÔNG cần internet):

  Cách 1 — có Node.js:
     mở Terminal/CMD tại thư mục này, gõ:
        npx serve .
     rồi mở địa chỉ hiện ra (vd http://localhost:3000)

  Cách 2 — có Python:
        python -m http.server 8080
     rồi mở  http://localhost:8080
